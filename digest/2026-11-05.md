## Research

- (2025-08)  AgentArmor — Enforcing Program Analysis on Agent Runtime Trace to Defend Against Prompt Injection
	- [[2508.01249] AgentArmor: Enforcing Program Analysis on Agent Runtime Trace to Defend Against Prompt Injection](https://arxiv.org/abs/2508.01249)
	- 問題: 信頼できない入力が権限を持つToolの実行にどう影響したか、個々のTool Callだけを検査してもその因果関係を把握できない
	- アプローチ: 実行履歴をProgram Dependency Graph（PDG）へ変換、LLMが生成した振る舞いを実行時に解析する
		- Agentの自然言語による推論とTool Callを、解析可能な中間表現へ変換する
		- ただし、依存関係の推定そのものにもLLMを使うため、決定的ではない
	- 制約と未解決課題
		- LLMによる依存関係推定の誤り
		- 追加の推論時間
		- 大規模なファイル操作時の追跡コスト
		- 適応的な攻撃による回避
		- 型システムを使っているからといって、形式的な安全性保証が得られたわけではない
