## Research

- Enclawed — Consensus-Governed, Hardware-Rooted Agent Runtime
	- [\[2610.33318\] A Deterministic Security Runtime for LLM Agents on MPI and Batch-Scheduled HPC Systems: Consensus-Governed, Hardware-Rooted Supervision of Every Rank](https://arxiv.org/abs/2610.33318)
	- [enclawed/enclawed-oss: The official Enclawed Open Source Core Repository](https://github.com/enclawed/enclawed-oss)
		- [enclawed/hpc-agentic-swarm-reproduction: Reproduction data, scripts and grader for the paper on Enclawed's deterministic security runtime for LLM agents on HPC (HASB R0-R11, A1-A3)](https://github.com/enclawed/hpc-agentic-swarm-reproduction)
	- 課題: 長時間実行されるジョブでは、起動後に権限が失効したり、実行ノードが侵害されたりする可能性がある
		- 起動時に許可されたことと、実行を継続してよいことは別問題
	- 解決策: Agentの実行許可を分散合意されたLeaseとして表現し、MPIの各Rankが継続的にそのLeaseを参照する
	- 望まれる結果: Control Planeが利用不能になった場合も、無制限にジョブを実行させるのではなく、停止する設計を実現
	- 制約: Supervisorはジョブと同じユーザー権限で動作するため、侵害されたプロセスがSupervisorを停止できる
		- = Leaseが失効しても実行中のRankを強制停止できない可能性がある
