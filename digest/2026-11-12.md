## Research

- RuntimeTickets: Source-Grounded Security Obligations for Agent Skills
	- [[2611.03772] RuntimeTickets: Source-Grounded Security Obligations for Agent Skills](https://arxiv.org/abs/2611.03772)
	- 問題:
		- Agent SkillにToolの使用権限を与えても、実際の操作がユーザーの依頼に沿っているとは限らない。
		- Toolや送信先が許可されていても、送信するデータと操作が現在のタスクに必要なものかを判断できない。
	- アプローチ
		- タスクごとにSecurity Ticketを生成し、そのTicketをRuntimeで強制
		- LLMを使うのはTicketの提案時だけで、実行時のEnforcementと監査結果の判定にはLLMを使わない
		- TicketはHostが与えた権限を縮小できるが、拡大できない
		- Ticketは実際に発生するネットワーク送信をタスクごとの条件で検査する
			- 送信するオブジェクトの妥当性まで確認する
	- 制約・未解決課題
		- 強制できるのが信頼されたMonitorから観測可能な副作用に限られる
			- 論文ではネットワークEgressを主要な強制点としている
		- 実際のネットワーク環境で全Egressを捕捉できるか、暗号化されたPayloadをどう検査するか、長時間実行時にbadgetとTicket状態をどう保持するかも、実運用に向けた重要な検証課題
