## [Platform Engineer（リードクラス）](https://hrmos.co/pages/bengo4/jobs/0007518)

>     募集背景
> 
> 当社では、弁護士ドットコム事業を始め、複数事業を運用し、新たなサービス展開なども行っております。そのため、今まで以上に各事業横断での開発者体験（DX）の向上と開発基盤の整備が求められておりPlatform Engineeringの取り組みを新たに導入するため、当社1人目となるPlatform Engineerを募集いたします。
> 
> 事業の成長に伴う開発チームの拡大や開発速度の要求の高まりに対応し、プラットフォーム基盤の構築と開発生産性の向上を担っていただける方を求めています。
> また、当社では新たな技術やAIツールを取り入れながら、従来の基盤整備の枠を超えた次世代のPlatform Engineering基盤構築にも挑戦していきます。
> 
> 技術革新に興味を持ち、新しいPlatform Engineeringの形を一緒に創造していける方のご応募をお待ちしております。
> 
>     ポジションについて
> 
> 職務詳細
> 
>     開発者向けプラットフォーム基盤の構築・運用
>     弁護士ドットコムを含む複数のサービス開発チームが効率的かつ快適に開発できるための、Internal Developer Platform（IDP）やCI/CDパイプライン、開発環境基盤などの選定・調査から実際の設計・構築・運用を行なっていただきます。
>     開発者体験（DX）の向上
>     開発者が価値創出に集中できる環境を実現するため、開発環境のセットアップ自動化、デプロイフローの最適化、ドキュメント・ナレッジ基盤の整備などを通じて、開発体験全体の改善に取り組んでいただきます。
>     開発生産性の改善と自動化の推進
>     IaCツールを活用したインフラ構築の標準化や、CI/CDパイプラインの最適化、テスト自動化基盤の整備などを通じて、開発サイクル全体の効率化とPlatform Engineering文化の推進に貢献していただきます。
>     Platform Engineering戦略の策定と推進
>      当社初のPlatform Engineerとして、全社横断での開発基盤の現状分析・課題整理を行い、中長期的なPlatform Engineering戦略の立案と実行をリードしていただきます。
> 
> ※当社1人目のPlatform Engineerとして、Platform Engineering領域のリード的ポジションでご活躍いただくことを想定しています。将来的にはSRE室をPlatform Engineering中心の組織へと成長させ、チームビルディングにも携わっていただけます。

>     インフラ : AWS / GCP /Akamai
>     データベース・データストア : Aurora MySQL / OpenSearch
>     ソースコード管理：GitLab / Github
>     構成管理：Terraform / CloudFormation
>     データ分析：Redash / trocco / BigQuery / Athena
>     ログ/データ収集：Fluentd / CloudWatch Logs
>     監視/モニタリング：DataDog
>     プロジェクト管理：Jira
>     チャットツール：Slack
>     AI：Cursor / Claude Code / Devin など
> 
> ポジションの魅力
> 
>     全社のエンジニアリング組織に影響を与える、真の0→1の挑戦
>     当社初のPlatform Engineerとして、プラットフォーム戦略から実装まで、すべてをあなたの手で設計できます。既存の仕組みに縛られることなく、理想的な開発者体験を追求できる環境です。
>     「組織のOS」を創る、システム思考の実践機会
>     単なるツールや基盤の構築ではなく、人・プロセス・技術を統合した「システムとしての組織」を設計します。技術的な深さと組織設計の両面で成長できるユニークなポジションです。
>     事業成長と直結するインパクト
>     複数の事業プロダクトを横断的に支援することで、社会的意義の大きい事業成長に直接貢献できます。あなたの基盤が、日本の法律アクセスを改善する一助となります。
>     最新技術とベストプラクティスを実践できる環境
>     クラウドネイティブ、Kubernetes、GitOps、Platform as a Product など、最新のPlatform Engineeringの考え方を実践できます。技術選定の自由度が高く、最適な技術スタックを提案・導入可能です
> 
>     サービス／事業部について
> 
> 弁護士ドットコム株式会社は「プロフェッショナル・テックで、次の常識をつくる。」をミッションとして、人々と専門家をつなぐポータルサイト「弁護士ドットコム®︎」「税理士ドットコム®」「BUSINESS LAWYERS®」、契約マネジメントプラットフォーム「クラウドサイン®」を提供
> 募集部門の紹介
> 
> 開発本部　SRE室
> 
> 弁護士ドットコムではサービスごとの事業部制を採用しており、開発エンジニアは開発本部に所属しながら各事業部のサービスを担当する体制を取っています。これはエンジニア間のノウハウ共有や技術的シナジーを促進するための組織構造です。
> 
> SRE室も開発本部の一部として、開発チームを支援する役割を担っており、複数サービスの安定稼働や開発基盤の整備を主なミッションとしています。
> 現在、SRE室ではPlatform Engineeringの取り組みを新たに開始し、開発者体験の向上と開発基盤の構築を推進するフェーズにあります。今回募集するPlatform Engineerは、当社初のポジションとしてSRE室に在籍いただき、Platform Engineering戦略の立案から実行までをリードしていただきます。
> 
> 将来的には、SREとPlatform Engineerが協力しながら、開発基盤とサービス信頼性の両面から全社のエンジニアリング組織を支える組織体制を構築していく予定です。
